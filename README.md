# Matthew Suess — Photography

A high-end photography portfolio built as static HTML, CSS, and JavaScript so it can live on **GitHub Pages** for free.

Live URL once Pages is on:

`https://kimmatt-svg.github.io/photography-portfolio/`

## Design references

The site borrows structure and restraint from photographers who treat the website as a gallery, not a template:

- [Nadia Lee Cohen](https://www.nadialeecohen.com/) — name as brand, an Enter screen, work listed as dated series
- [Peter Lindbergh / Obys](https://peterlindbergh.obys.agency/) — monumental type, horizontal viewing, chapters instead of grids
- [Mario Testino](https://mariotestino.com/) — series as stories, full-bleed pictures, almost no chrome
- [Tyler Mitchell](https://tylermitchell.co/) — the photograph is the interface; looking is unhurried

## GitHub Pages

Yes. This repo is already set up for it.

1. Push to `main`
2. In the repo: **Settings → Pages → Deploy from a branch**
3. Branch `main`, folder `/ (root)`

The current pictures are Unsplash stand-ins. Swap them for your own files in `assets/work/` and update titles, years, and the contact email in `js/data.js`.
